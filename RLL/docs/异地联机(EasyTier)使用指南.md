# RLL 异地联机（EasyTier）使用指南

适用版本：RLL 1.3.9（EasyTier 核心 v2.6.4）

本指南面向需要与朋友在不同网络环境下一起玩 Minecraft 的用户。启动器内置了 EasyTier 组网能力，双方加入同一网络后，即可在游戏内用对方的虚拟 IP 直连，无需公网服务器。

## 1. 前置条件

- Windows 10 / 11，已安装 Java（启动器会自动检测）。
- 双方都已下载并解压 `RLL-1.3.9-win-anycpu.zip`，运行 `rll.exe`。
- 双方网络能访问 GitHub Release（用于首次下载 EasyTier 核心，约 32 MB）与公共节点。
- **启动器必须以管理员身份运行**（创建虚拟网卡 TUN 设备需要管理员权限；非管理员会报 "tun device error: The file is not signed"）。

## 2. 双方共同配置（开服方与加入方都要做）

1. 打开启动器，进入「设置」页。
2. 勾选「启用异地联机（启动游戏时自动加入网络）」。
3. 填写**网络名**（1–64 位，仅字母、数字、`-`、`_`），例如 `my-friend-net`。
4. 填写**网络密钥**（双方必须完全一致；以明文保存在配置文件中，只与可信的人共享）。
5. 公共节点：从下拉选择一个本机实测可连通的节点，或手动填写 `tcp://节点地址:11010`。节点由社区维护，可能失效；点「查看全部节点」打开监控站查看当前可用地址。
6. 点击「下载核心」：首次约 32 MB，会校验 SHA256；状态行显示「核心已就绪」即完成。核心存放于 `%APPDATA%\rll\bin\easytier-core.exe`（便携模式下为 `data\bin\`）。
7. 点击「保存设置」。

> 网络名与密钥双方必须**完全一致**（含大小写），否则无法组网。

## 3. 开服方步骤

1. 以管理员身份运行 `rll.exe`，启动游戏。
2. 游戏进入主菜单后，点击「对局域网开放」（Open to LAN），记下端口（默认从 25565 起）。
3. 启动器启动游戏时会自动加入 EasyTier 网络；设置页「虚拟 IP」会显示本机地址（形如 `10.x.x.x`）。也可点击「复制 IP」。
4. 把 `虚拟IP:端口` 发给加入方（例如 `10.144.1.2:25565`）。

## 4. 加入方步骤

1. 以管理员身份运行 `rll.exe`，启动游戏（同样会自动加入同一网络）。
2. 进入游戏「多人游戏 → 直接连接」，填写开服方发来的 `虚拟IP:端口`，点击连接。

## 5. 验证联机成功

- 加入方能进入开服方的世界，且能正常交互。
- 若提示「无效会话」（Invalid session）：说明对方服务器开启了 `online-mode`（正版验证），而当前使用的是离线账号。解决方式：
  - 在「账号」页登录对应认证服务器的第三方认证账号（authlib-injector），或
  - 让服务端把 `online-mode` 设为 `false`。
- 组网成功只代表网络通了，不代表能通过服务器的正版验证。

## 6. 常见问题与排查

### 6.1 虚拟 IP 一直不显示

- 确认启动器以管理员身份运行（非管理员无法创建 TUN 设备）。
- 打开设置页「查看核心日志」，查看诊断结论与原始输出。
- 常见诊断：
  - `unexpected argument`：核心版本与启动器不匹配，点「下载核心」更新。
  - `tun device error / The file is not signed`：以管理员运行；或缺少 `wintun.dll`（启动器会自动补齐，失败时可从 https://www.wintun.net 手动下载放到核心同目录）。
  - `AddrInUse`：端口 11010–11013 被占用（残留 `easytier-core.exe`），在任务管理器结束进程后重试。
  - 防火墙 `0x80070005`：权限不足，以管理员运行。

### 6.2 公共节点不可达

- 社区节点可能失效；点「查看全部节点」打开监控站，选择当前可用节点填入「公共节点」。
- 可用节点示例（本机实测 TCP 可连通）：
  - `tcp://easytier.weiai.org.cn:11010`
  - `tcp://et.sumnight.top:11010`
  - `tcp://225284.xyz:11010`

### 6.3 启动器关闭后仍有 easytier-core 进程

- 正常情况下启动器退出时会自动结束核心进程。若残留，可在任务管理器手动结束 `easytier-core.exe`。

### 6.4 端口被占用提示

- 启动前启动器会检测端口 11010–11013；若被占用会提示。结束残留进程后再启动。

### 6.5 网络名/密钥校验

- 网络名只允许字母、数字、`-`、`_`（1–64 位）；非法字符会被清空。
- 密钥最长 128 位。

## 7. 安全提示

- 网络密钥以明文保存在配置文件（`%APPDATA%\rll\config.json`）中，它是网络的准入凭证；请只与可信的人共享网络名与密钥。
- 组网为 P2P 直连，不经过启动器服务器；启动器不修改 `server.properties`，只负责组网与显示 IP。
- EasyTier 核心固定版本 v2.6.4 + SHA256 硬校验，只作为子进程运行，不加载为库。

## 8. 关闭联机

- 在设置页取消勾选「启用异地联机」并保存；下次启动游戏将不再加入网络。
- 关闭启动器时核心进程会被自动结束。

## 9. 推荐模组：mcwifipnp（更高级联机设置）

`mcwifipnp`（LAN World Plug-n-Play）是与 EasyTier 配合使用的推荐模组，它改进了游戏内「对局域网开放」的界面，提供：

- **自定义端口**：不再局限于 25565，可指定任意 1024–65535 端口，避免端口冲突。
- **在线模式开关**：可关闭正版验证（online-mode），使使用离线账号的玩家也能加入（EasyTier 组网成功后，离线账号仍可能被正版验证拒绝，此开关可解决）。
- **UPnP 端口映射**：自动向路由器映射游戏端口（仅在路由器支持 UPnP 时有效）。
- **复制 IP**：一键复制当前设备 IP，方便分享给对方。

### 9.1 安装

1. 确保已安装 Fabric 与 Fabric API（`fabric-api-*.jar`）。
2. 将 `mcwifipnp-2.1.4-26.3-fabric.jar` 放入 `<游戏目录>\mods\`。
3. 启动游戏，确认 Mod 已加载（模组菜单中可见 "LAN World Plug-n-Play"）。

> 版本对应：mcwifipnp 2.1.4 支持 Minecraft 26.3（Fabric Loader ≥ 0.18.4，Java ≥ 21）。

### 9.2 与 EasyTier 配合使用

1. 双方按本指南 §2 完成 EasyTier 配置并启动游戏。
2. 开服方：进入要分享的世界 → 按 `Esc` → 「对局域网开放」，此时会显示 mcwifipnp 的高级界面。
3. 设置端口（建议固定一个端口，如 25565，便于对方记忆），并根据需要关闭「在线模式」（offline 账号加入时必须关闭）。
4. 点击「开始」开放世界；记下显示的 `虚拟IP:端口`（或点「复制 IP」）。
5. 将 `虚拟IP:端口` 发给加入方，加入方在「多人游戏 → 直接连接」中输入即可。

### 9.3 在线模式说明

- **开启在线模式**：仅允许使用正版/Microsoft 账号或第三方认证账号（authlib-injector）的玩家加入；离线账号会被拒绝并提示「无效会话」。
- **关闭在线模式**：所有账号（包括离线账号）均可加入，但无法验证玩家身份，适合与朋友私密联机。
- EasyTier 组网成功只代表网络通了，不代表能通过服务器的正版验证；如需正版验证，请在「账号」页登录第三方认证账号，或让开服方开启在线模式并使用对应账号。

### 9.4 端口建议

- EasyTier 虚拟网络中端口通常无冲突，建议双方约定固定端口（如 25565）。
- 若端口被占用，mcwifipnp 会提示「端口不可用」，换一个端口即可。
- UPnP 映射在 EasyTier 虚拟网络中通常无效（虚拟网卡不支持），可忽略；直接用虚拟 IP 直连即可。
