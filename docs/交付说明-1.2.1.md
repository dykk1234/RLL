# RLL 1.2.1 交付说明

本包为 **1.2.0 → 1.2.1** 的完整改版源码（LiteLauncher 工程），依据《RLL 1.2.0 深度技术评析报告》与
PCL2 参考功能实现。本机环境无 .NET 运行时，源码经静态复查（括号配对、C# 5 语法扫描、
残留引用清理），**请在 Windows 上执行下方构建与测试命令完成最终验证**。

## 本版改动一览

| 类别 | 内容 |
| --- | --- |
| 修复 F1 | TLS 声明与实际不符：探测逻辑上移为 `HttpUtil.ChooseSecurityProtocol()`，静态构造与 `Program.Main` 共用同一套结果 |
| 修复 F2 | 超长命令行：>30000 字符且 Java 9+ 自动改用 `@argfile`（参数文件启动后清理）；Java 8 超限给出明确错误 |
| 修复 F4 | 死代码：删除 `AppPaths.CacheDirectory` 及创建逻辑 |
| 修复 F5 | 版本统一 1.2.1（程序集 / FileVersion / InformationalVersion / FallbackVersion） |
| 新功能（参考 PCL2） | 账号系统：离线账号 + 第三方认证账号（authlib-injector，对应 PCL2 Auth 登录）；联机：可进入认证服务器的正版模式（online-mode=true）服务器 |
| 新功能 | authlib-injector 一键下载（官方 1.2.5，固定版本）或选择本地 JAR；`-javaagent` 自动注入 |
| 安全 | 认证服务器主机默认不受信任，用户添加预设/登录成功后才加入运行时白名单；密码绝不落盘；yggdrasil 请求仍强制 HTTPS+443+重定向复检 |
| UI | 新增「账号」页；启动页用户名输入框改为账号下拉 + 管理入口 + 状态提示；导航 7 页；模组页懒加载索引同步 |
| 测试 | 新增 11 项离线测试 + UiSmoke 页面数/控件断言更新 |

## 建议手动验证的联机链路（Windows）

1. 打开「账号」页，选择内置 LittleSkin 预设或输入认证服务器地址（https://...）。
2. 输入账号密码登录，确认状态显示「登录成功」；启动页账号下拉出现「显示名（主机）」。
3. 点击「下载注入器」（或选择本地 authlib-injector.jar），确认状态「注入器已就绪」。
4. 启动页选择该认证账号并启动游戏，日志应出现 `-javaagent:...` 注入参数；
   进入目标服务器后若为 online-mode=true 服务器，应能通过 hasJoined 校验（联机成功）。
5. 「校验令牌」可检查会话是否仍有效；「删除账号」会同步清除会话令牌。
