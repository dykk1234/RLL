# RLL 1.3.0 交付说明

本版依据《RLL 1.3.0 开发需求规格》实现四项新功能，并修复启动页 Java 标签换行问题。
所有代码均在 Windows 上实际编译并跑通测试（不是静态复查）。

## 本版改动一览

| 类别 | 内容 |
| --- | --- |
| 修复 | 启动页 Java 标签折行：标签列改 AutoSize + 单行省略号 + 文案精简 |
| 新功能 P0 | EasyTier 异地联机：设置页开关/网络名/密钥/节点/核心下载/虚拟 IP 复制 |
| 新功能 P1 | 下载源镜像切换：官方 / BmclAPI / 自定义 HTTPS |
| 新功能 P1 | 版本隔离：每版本独立存档/配置/模组 |
| 新功能 P2 | 模组冲突与依赖检查：安装前提示，不阻止 |
| 安全 | EasyTier 核心固定版本 + SHA256 校验；镜像只换地址不改校验；配置 ACL 收紧 |
| 文档 | README / SECURITY / CHANGELOG 同步；修正 1.2.1 的 EasyTier"不可行"表述 |

本机实测结果：

## 需要你在本机手动验证的链路

以下依赖真实网络/双机环境，本环境无法代跑：

### 1. EasyTier 联机（需两台机器）

1. 两台机器都安装 RLL 1.3.0，设置页勾选「启用异地联机」，
   填入**相同**的网络名与密钥，点击「下载核心」等待状态变为「核心已就绪」。
2. A 机启动游戏并在游戏内「对局域网开放」，记下端口（默认 25565 起）。
3. A 机设置页「虚拟 IP」应显示 `10.144.x.x`；若未显示，说明公共节点不可达，
   可在「公共节点」填入其它节点地址。
4. B 机加入同一网络后，在游戏「多人游戏 → 直接连接」填 `A机虚拟IP:端口`。
5. 关闭启动器后确认任务管理器里 `easytier-core.exe` 已退出（无孤儿进程）。

### 2. 下载源镜像

设置页把「下载源」切到 `BmclAPI 镜像`，新装一个未安装的版本，日志里应出现
`bmclapi2.bangbang93.com` 的下载地址，且安装完成后 SHA1 校验通过。

### 3. 第三方认证联机（1.2.1 已有能力）

账号页添加认证服务器 → 登录 → 启动页选择该账号 → 进游戏连对应服务器。

## 边界与已知限制

- **EasyTier 公共节点**：`tcp://public.easytier.top:11010` 是官方文档维护的公共节点，
  稳定性因网络环境而异；不可达时可自行换节点。核心版本固定为 `v2.6.4`，
  新版核心需重新核对 SHA256 后才能升级（不会自动跟随 latest）。
- **虚拟 IP 探测**：优先扫描本机 `10.144.0.0/16` 网卡；若核心未创建网卡（公共节点不可达），
  15 秒后仍返回空并只给出提示，游戏照常启动。
- **镜像完整性**：BmclAPI 等第三方镜像可能滞后或不完整，仅作备用；Modrinth 不镜像。
- **版本隔离**：只创建目录，不迁移既有存档；迁移需手动复制 `saves`。
- **模组检查**：按"文件名包含 slug"做宽松匹配，只用于提示，不会删除任何文件。
- **未实现**（与需求规格一致）：微软官方登录、代码签名、自动更新、自研 NAT 打洞、
  内置服务端、皮肤站集成。
- authlib-injector 仍无上游哈希（官方不提供），只做固定地址 + 大小上限 + JAR 结构校验。
