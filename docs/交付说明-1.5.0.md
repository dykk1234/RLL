# 交付说明 — 1.5.0

本版本为一次功能迭代（语义化版本：次版本号新增功能），围绕五个目标落地：
轻量化、联机独立页与稳定性、可设置性与美观度、已知 bug 修复、新功能扩充。

## 一、轻量化（磁盘占用治理）

**核心原则**：只统计、只清理「可再生」内容；版本 JAR、资源索引、存档、模组一律不触碰。

| 条目 | 路径 | 清理后果 |
|---|---|---|
| 启动器/游戏日志 | `%APPDATA%\rll\logs` | 保留当天正在写的文件 |
| 崩溃报告 | `<游戏目录>\crash-reports` | 下次崩溃重新生成 |
| @argfile 残留 | `%APPDATA%\rll\rll-args-*.txt` | 纯临时文件 |
| natives 解压缓存 | `<游戏目录>\natives` | 下次启动自动重新解压 |
| 联机核心 | `%APPDATA%\rll\easytier` | 下次联机重新下载（约 6MB），运行中时拒绝清理 |
| 版本与资源 | versions / assets / libraries | **不可清理**（仅展示） |

- 入口：设置页 →「存储与日志（轻量化）」卡。首次进入设置页自动统计（只统计一次，
  避免每次进入都遍历 versions/assets）；「重新统计」按钮手动刷新。
- 新增配置：`LogRetentionDays`（3–90，默认 14）、`LogMaxRotatedFiles`（1–10，默认 2）、
  `CleanTempOnExit`（默认开）。日志策略在 Program 启动即生效（先于首次过期清理）。

## 二、联机独立页 + 节点实时监测

- 侧栏第 5 项新增「联机」页（矢量图标随主题着色）；原设置页 EasyTier 卡**整体迁入**，
  字段、校验、下载流程、虚拟 IP 展示全部不变。
- 新增「公共节点测速」卡：
  - 探测方式：TCP Connect 握手耗时（`NodeMonitor.Probe`，超时 3s，并发探测）。
    `udp://` 节点按 TCP 探测仅代表主机可达，界面已注明。
  - 结果排序：可用优先、延迟升序；状态列给出 优/良/可用/不可达 分级。
  - 交互：双击行、「切换到最优节点」按钮均可把节点设为默认（写配置即生效）。
  - 自动测速：30 秒周期，仅当「联机页可见 + 开关打开」时运行（WinForms Timer，
    切页自动停），不产生后台常驻流量。
- 退出启动器时自动停止测速定时器。

## 三、可设置性与美观度

- 强调色五选一：蓝（默认）/绿/紫/橙/玫瑰。实现为 `UiTheme.ApplyAccent` 覆写
  Accent/AccentDark/AccentSoft 三色，深浅色模式兼容；即改即存，重启完全生效
  （既有控件颜色在构建时固化，界面有明确提示）。
- 界面字体缩放：90%–130% 五档，`UiTheme.SetFontScale` 在构建 UI 前应用，重启生效。
- 新配置键：`AccentColor`（blue/green/purple/orange/rose）、`UiFontScale`。

## 四、bug 修复（承接 1.4.8 审核结论）

1. **崩溃分析突破 8MB 门**：此前文件 >8MB 直接放弃分析（多模组 latest.log 极易超限）。
   现尾读改为 2MB 字节窗（`FileStream.Seek(-N, End)` + `FileShare.ReadWrite`），
   任意大小日志均可分析；窗口切点处截断的半行会被丢弃。
2. **崩溃关键词收紧**：移除裸 `"Failed to load"`（误报"资源包损坏"）、
   `"No such file or directory"`（误报"本地库缺失"）、`"OpenGL error"`（光影正常日志误报）。
3. **崩溃结论呈现**：按严重度排序（Error 优先）、同名模式去重、最多 5 条。
4. **跨框架兼容**：`PathUtil` 与测试中的 `File/Directory.GetAccessControl` 静态重载
   （net6 已移除）改为 `FileInfo/DirectoryInfo` 实例式 API，行为不变。

## 五、页面索引变更（开发者须知）

导航现为：启动0 / 账号1 / 下载2 / 模组3 / **联机4** / 设置5 / 日志6 / 关于7。
