# 交付说明 — 1.6.0

本版为「基础能力收敛」迭代，按《RLL 1.6.0-1.9.0 详细产品需求与技术开发文档》冻结范围落地五个 P0：
F-1601 统一下载管理中心、F-1602 ModIndex 统一模组索引、F-1603 模组批量更新与回滚、
F-1604 DPAPI 凭证保护与迁移、F-1605 MainForm 渐进拆分起步（M1）。

## 一、F-1601 统一下载管理中心

- 新增「下载任务」导航页（索引 3，模组/联机/设置/日志/关于顺延），全部下载统一排队调度。
- `DownloadManager`：默认并发 3（可配 1–8）、历史上限 100；按优先级两轮调度；
  支持暂停（仅 AllowResume 且 EnableDownloadResume 的任务）/ 重试 / 取消 / 清空历史。
- 状态机：Queued → Running → Verifying → Completed / Failed / Canceled / WaitingRetry；
  进度回调算速度与 ETA（采样 ≥0.5s）。任务元数据落盘 `download-tasks.json`
  （不含任何凭证）；未完成任务启动时恢复为 WaitingRetry，重走 HTTPS 白名单与哈希校验。
- 安全边界：恢复任务不静默续传；仅校验失败的完整重下；执行器默认复用 HttpUtil
  （DownloadFileAsync / DownloadFileNoChecksumAsync）。
- 已知取舍：当前只托管模组更新链路；版本 / 资源 / Java 下载仍走既有页面（README 已注明）。

## 二、F-1602 ModIndex 统一模组索引

- `ModIndexService`：按实例缓存，文件签名（长度 + LastWriteTimeUtc.Ticks）命中即复用，
  二次扫描不重复解析未变化 JAR；`force=true` 强制重扫（检查更新用）。
- 解析 fabric.mod.json（>256KB 判 Invalid，缺失回退文件名，异常容错不中断）；
  GameVersionRange 取 depends.minecraft；五段依赖映射（required/optional/suggests/conflicts/breaks）。
- 同时索引 .jar 与 .jar.disabled（禁用状态一致）；GetByModId 忽略大小写。

## 三、F-1603 模组批量更新与回滚

- 模组页新增「检查更新 / 更新所选 / 回滚」。「检查更新」用同一 ModIndex 快照查询
  Modrinth 版本，按游戏版本选最优版本与主文件；预览对话框默认只勾选
  「明确兼容且无冲突」项，冲突 / 依赖缺失 / ModId 重复 / 禁用模组标黄不勾选。
- 单模组事务：下载（SHA1，Priority=1，可续传）→ 校验 → 备份旧版 → 原子替换 →
  更新索引 → 写历史；失败恢复旧文件；批量逐项隔离，不整批回滚。
- 备份：`<DataDirectory>\modbk\<实例>\<模组>\bk-<UTC时间戳>.jar` + `.jar.sha1`，
  默认保留 3 份；回滚前核验备份 SHA1，篡改备份拒绝恢复；回滚时先把当前版本再留一份链。
- 注意：备份条目未写版本号（文件名时间戳标识），为已知简化，后续版本补。

## 四、F-1604 DPAPI 凭证保护与迁移

- 账号 AccessToken / ClientToken 与 EasyTier 网络密钥改由 `ProtectedData`（当前用户，
  熵盐 rll-cred-<用途>）加密后落盘；算法标记 dpapi / plain（version=1）。
- 迁移：旧明文配置首次加载自动一次性 Protect 并立即重写（CredentialsMigrated 标志防重复）；
  解密失败保留密文不清空，要求用户重新登录 / 重输密钥；非 Windows 降级 Base64 并提示。
- `Log.Sanitize` 统一脱敏（键：accessToken/clientToken/authorization/easytierNetworkSecret/
  secret/password/passwd，支持引号与无引号值）；日志、崩溃、任务历史、导出无明文。

## 五、F-1605 MainForm 拆分起步（M1）

- MainForm 改 partial；下载任务页构建与操作处理整体抽入 `src/MainForm.TasksPage.cs`
  （BuildDownloadTasksPage / 刷新 / 按钮处理），编译 0 错误、行为不变。
- M2（事件处理抽离）/ M3（应用服务层）/ M4（重复逻辑删除）留待后续版本；
  M1 不以行数下降为完成标准，以可编译可冒烟为准。

## 六、版本与配置
