# 交付说明 — 1.7.7

本版为「版本隔离收口 + 界面美化」迭代，主体是修复 B-21：1.7.6 修好了模组「写到哪」，
但没修好游戏「从哪读」，也没修好启动时把共享模组广播给每一个版本，三处口径分叉。

## 一、目标版本唯一真相源（B-21 根因 1）

- 模组目录、光影目录、`--gameDir`、进程工作目录四处统一取「启动页当前选中版本」。
- 模组页 Fabric 下拉框降级为「模组适配版本」筛选语义，不再作为写入目标；
  启动版本变化、进入模组页时自动对齐，`RefreshInstalledVersions` 不再无条件选中第 0 项。
- 「当前管理目录」改为带底色徽章，直接写出所跟随的启动版本 ID。

## 二、启动链路的硬保障（B-21 根因 3）

- `GameLauncher.BuildPlan` 强制校正 `--gameDir`：兼容两段式（`--gameDir <值>`）、
  `--workDir`、`--gameDir=<值>` 合写；上游完全未写时自动补一段。
- `plan.WorkingDirectory` 改为实例目录；`Prepare` 兜底创建实例目录。
- `JvmArgumentPolicy` 新增禁止自定义 `-Duser.dir=`，封住通过系统属性改写工作目录的旁路。

## 三、取消自动搬运（B-21 根因 2）

- 移除 `SeedInstanceMods`（启动时把共享 `mods` 全量复制进实例）与
  `SeedSharedModsFromInstance`（关闭隔离时把各实例模组聚合回共享目录）。
- 改为模组页显式「从共享目录导入」按钮：只作用于当前版本，只复制、不覆盖、不删除。
- 共享目录仍有模组而当前实例为空时，启动前给出可照做的提示，不静默改动用户文件。

## 四、界面美化

- 卡片：柔和投影 + 顶部主题色渐变细条 + 圆角 14px；主按钮渐变自绘、悬停提亮；
  次按钮悬停边框点亮；导航选中态横向渐变 + 悬停提示条；状态栏进度条渐变填充；
  侧栏品牌区渐变分隔线。
- 主按钮不在 `HandleCreated` 调用栈内设置 `Region`，避开 WinForms
  `CreateHandle()/Dispose()` 时序陷阱。

## 五、补遗（同日）

- 关于页补齐 1.7.x 能力与「最近更新（1.7.7）」小节；「暂不支持」收窄为
  Forge / NeoForge / Quilt、整合包导入、自动更新、遥测。
- 模组页按钮溢出：`UiFactory.CreatePage` 唯一列补 `ColumnStyle = 100%`。
  实测修复前搜索按钮 X=1990、底部按钮 X=1189（1080 宽窗口），修复后搜索按钮
  X≤1017，1080 / 980 两档窗口均正常换行。

## 六、打包与校验

- `SHA256SUMS.txt` 与包内 `rll.exe.sha256` 使用 LF 行尾，`sha256sum -c` 在 Git Bash 可直接校验。
- `pack.ps1` 注释保持 ASCII（PowerShell 5.1 以 ANSI 读无 BOM UTF-8，乱码注释曾吞掉下一行代码，
  导致包内校验文件 0 字节）。
- **本次发版额外修正（未在 1.7.7 原包里出现）**：`pack.ps1` 过去只复制根目录 `*.md`，
  `docs\` 下的交付说明从未进入源码包；`LICENSE` 也不在任何产物内。两者已在发版树中补齐。

  运行包内 exe 与 `dist\rll.exe` 字节一致（SHA256 均为
  `077938BE…68166A`）。
